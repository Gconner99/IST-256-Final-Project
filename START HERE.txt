PHOSPHENE
=========

Do NOT open the files inside Cursor.
Cursor will show the code instead of running the program.

WHY CHROME WAS CRASHING
------------------------

Phosphene needs WebGL. Your everyday Chrome window uses the graphics
card. On this PC that driver kills the tab.

Start Phosphene.bat now opens a PRIVATE Chrome/Edge window that does
not use that graphics card. Do not open PHOSPHENE.html by itself.


HOW TO OPEN IT (Windows)
------------------------

1. Delete any OLD unzipped folder (Downloads names like "... (25)"
   are stale).
2. Download a NEW ZIP and unzip the WHOLE folder. You must see
   PHOSPHENE.html AND phosphene.js sitting next to each other.
3. Open File Explorer (folder icon on the taskbar, or Windows key + E).
4. Double-click:

      Start Phosphene.bat

   A black command window flashes, then a NEW Chrome or Edge window
   opens. THAT window is the program.

   The picture should look sharp again (Preview quality, full size,
   grade/bloom). Use the top-bar quality menu if you want Draft/Full.

   If that window crashes: double-click  Start Phosphene Safe.bat
   instead. The picture will be softer, but Chrome should stay up.


HOW TO OPEN IT (Mac)
--------------------

1. Open Finder (not Cursor).
2. Go to the Phosphene folder.
3. Right-click  Start Phosphene.command  → Open.


HOW TO USE IT
-------------

- Drag a photo, video, or MP3 onto the big dark area
  OR click Plasma / Noise / Bars / Stars / Marsh / Oil / Paper / Cave / Stage / Sketch / Felt / Foil / Plush / Yarn / Sequins / Quilt / Cork / Gingham / Sprinkle / Velvet / Floaters on the left
  (that click puts the place on the picture)
- Type a prompt on the left and click Generate to make a NEW image. Again rolls a new seed.
- Drop an MP3 to use it as a soundtrack. Hit Play — idols, floaters, and places move with the mix
- Click Stamp floaters / Stamp idol / Stamp chaos (new seeds and wardrobe, same place)
- Idol Grow / Coat pick petals, halo, wings, horns, crystals, puff, cream / jelly / grape / ice / lava paint, etc. Floaters Kit picks toy-pop (piano, guitar, notes, boombox), votives, moths, charms
- Sketch is a composition-notebook / sticker-album place (cream paper, tape, doodles)
- Felt / Foil / Plush / Yarn / Sequins / Quilt / Cork / Gingham / Sprinkle / Velvet are textured toy-pop places
- Click Print frame to turn the live picture into a still
- Click Rand all for a new look. Rand wacky stays pretty (cream / toy-pop).
- Click New at the top to start over
- Move the sliders. Click Export to save.
- Click 2s / 4s / 8s mp4 for a short video clip. Wait until the status says saved.
  Clips are silent for now; the motion still follows the song.
  Check "close loop" so the last beats fade into the first frame.
